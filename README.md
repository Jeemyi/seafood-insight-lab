# SEAFOOD INSIGHT LAB

**결론부터 읽는 수산 시장 리서치** · MARKET INSIGHT LAB의 구조를 수산·유통 시장에 맞춰 독립적으로 만든 정적 웹사이트.

## 제공하는 화면

- **00 오늘의 브리핑**: 장식용 소개 배너 대신 실제 생성된 분석의 결론·대표 근거·데이터 상태를 압축해 표시. 근거가 부족하면 결론을 꾸며내지 않음.
- **01 핵심 시장 분석**: 서로 다른 기사와 공식 수치를 교차 비교해 가격·수급·소비·유통구조의 변화를 설명. 결론 → 수치 비교 → 인과 경로 → 구조적 발견 → 반가설 → 후속 지표.
- **02 데이터 리서치**: 노르웨이 통계청 SSB의 연어 생물 수출 FOB 가격(공개 API)과 한국은행 ECOS 환율(별도 무료 API 키)로 전주·전년 동기·가능하면 과거 3년 동기 평균 비교. AI가 해석, 계산은 Python이 수행.
- **03 참고 기사/질문 묶음**: 서로 다른 출처를 교차해서 검토하는 *질문*으로, 리서치 결론과 분리.
- 주요 기사, 검색 가능한 전체 기사 목록, 기사별 관련 시장·가격/수급/정책 변화·후속 확인 통계·읽음/저장.
- 10분 루틴, 분석 프레임, KMI/해양수산부/관세청/KATI/한국수산회/노르웨이수산물위원회 등 공식 자료 링크.

## 반드시 알아둘 한계

1. **SSB 수출 FOB 연어가격은 한국 업체의 실제 매입단가가 아닙니다.** 물류/보험/가공·규격/환율/계약 시점이 다릅니다. 실제 납품가격과 채널 이익률을 공개자료만으로 산출하지 않습니다.
2. ECOS 환율은 `ECOS_API_KEY`를 연결해야 자동 갱신됩니다. 키가 없다면 SSB 지표만 시도하고 환율 지표는 비어 있을 수 있습니다.
3. KMI·수협·관세청의 데이터는 **공개·안정적인 RSS/API를 확인하지 못한 항목에 한해 자동 수집하지 않습니다.** 읽기 링크만 표시합니다.
4. Google News **공개 검색 RSS**와 공개 언론사 RSS를 수집합니다. RSS가 느리거나 차단되면 기사 수가 줄어들 수 있으며, Google 뉴스 링크는 원문으로의 중간 연결일 수 있습니다.
5. 새 분석이 생성되지 않으면 마지막에 게시한 보고서를 원래 작성일과 함께 유지합니다. 첫 실행에서 이전 보고서가 없으면 사실 브리핑 또는 작성일이 표시된 과거 공개자료 시연을 보여줍니다. 추측성 숫자를 생성하지 않습니다.
6. 본 사이트는 공개 시장 상황을 읽기 위한 개인 학습용입니다. 회사 내부 매출 구성·점포 수·구매원가·매출이익률 등 **내부 수치는 코드·화면에 포함하지 않았습니다.**
7. 개인 GitHub Pages로 게시하면 웹페이지는 공개 접근 가능합니다. 민감한 문서·API 키를 GitHub 저장소 파일에 넣지 마세요.

## 로컬에서 실행

```bash
python -m pip install -r requirements.txt
python build.py
```

`site/index.html` 열기. 시연(2026년 10월 Norwegian Seafood Council 발표와 SSB 44주차 공식자료를 사용, 실시간 아님):

```bash
python build.py --demo
```

## 자동화

`.github/workflows/daily.yml`: KST 매일 06:00에 1회 실행 시도. 예약 작업은 지연·누락될 수 있으며 수동 실행도 가능.

Secrets: `OPENAI_API_KEY`(AI 리포트, 선택), `ECOS_API_KEY`(한국은행 환율 자동 수집, 선택). 기존 FRED API 키는 이 프로젝트에 필요하지 않습니다.

**무료 API 크레딧**을 사용하는 경우에도 AI API 사용량만큼 차감됩니다. 프로젝트 사용량을 확인하고 별도 과금 설정을 신중하게 관리하세요.

## 라이선스 / 데이터 출처

- SSB PxWeb v2: [공식 통계 API](https://www.ssb.no/en/api/pxwebapiv2) 및 [연어 수출 가격](https://www.ssb.no/en/statbank/table/03024/) (CC BY 4.0).
- 한국은행 ECOS: [경제통계시스템](https://ecos.bok.or.kr/).
- 기사 출처: 각 RSS 기사 원문 및 발행처 표시. 기사 전문을 복제하지 않음.

## v2 편집 기준

- 고정 홍보 문구 대신 오늘의 시장 브리핑을 우선 표시합니다.
- **수출액 기록과 물량/가격 분해**, **수산 어종 간 공급구조 차이**, **유통채널 변화**처럼 여러 근거를 맞대야 확인되는 결론을 우선합니다.
- ‘인사이트’를 내용상의 반복 수식어로 사용하지 않고, 분석·브리핑·통계·뉴스로 역할을 구분합니다.
- 회의자료는 관심 범위만 결정하고 내부 가격/매출/계약조건은 자동 생성 대상에 넣지 않습니다.
- 실제 자동 분석문 품질은 공개 RSS 소개문·API 데이터의 밀도에 달려 있습니다. 시연 원고가 실시간 자동 작성 수준을 보장하지 않습니다.


## v3에서 바뀐 점
- 화면과 리포트의 한국어를 자연스럽게 고쳤습니다.
- AI 입력 기사 후보를 분야별로 분산합니다. 수산물만이 아니라 유통·온라인·해외·안전 규정도 함께 검토합니다. 실제 분석은 근거가 충분한 주제만 게시합니다.
- 시연 화면의 기타 3개 주제 카드는 실제 뉴스가 아니라 **분석 범위 예시**로 표시합니다.
- 공식 자동 가격 통계는 여전히 연어(SSB)와 환율(ECOS) 중심입니다. 새 가격 통계가 자동으로 추가된 것은 아닙니다.

## v4: 이번 분석 누락 문제 해결
- 3회까지 재작성, 채널 분류 오류 자동 정규화, 동일 출처의 수출액/수출량 변화율에서 계산 가능한 평균단가 변화까지 검증 허용.
- 단순 RSS 제목·요약만으로 분석하지 않도록 OpenAI Responses API의 `web_search`를 이용해 공신력 있는 공개 근거와 원문 링크를 추가 수집. `gpt-6.1-sol`를 기본 모델로 사용하며 검색 호출에 따른 비용이 발생할 수 있음.
- 검증 실패의 내부 기술 메시지는 공개 사이트에서 숨김. 이전에 게시한 분석을 작성일과 함께 보존.
- 시연에는 연어시장과 홈플러스·대형마트 유통시장 분석 2편 수록. 두 편 모두 **편집용 과거 자료**로, 자동 생성된 최신 리포트가 아님.
- 보고서를 날마다 새롭게 생산하는 것까지 보증하지는 않음. 출처가 부족하면 지난 글이라고 표시하고 재사용.
- 변경된 `.github/workflows/daily.yml`도 적용해야 매일 오전 6시 실행·보고서 보존이 작동함.
