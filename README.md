## v5.7 검색·추가 조사 개선 (2026-11-11)

- **검색 단계 분리:** 최근 뉴스·공식 자료를 폭넓게 찾는 1차 조사 후, 선정 후보의 가격·수급·수출입·유통 근거를 찾는 2차 집중 조사를 수행합니다. 두 검색은 서로 다른 주제별 검색 계획을 사용합니다.
- **RSS 26개 짧은 검색어:** 긴 `OR` 조합 대신 각 어종·유통·제도별 2~4단어 검색문을 사용합니다. 그 외 기존 뉴스 피드에 KOSIS 공식 월간동향/최근 수록자료 피드를 추가합니다. RSS 발표일을 임의로 바꾸지 않습니다.
- **사건 기반 추가 조사:** 각 분야의 최고 점수 기사 하나만 AI에 넘기던 방식을 없애고, 분야별 최대 4개 사건을 포함하는 최대 20개 후보를 조사합니다. 점수가 높은 동일 분야 사건도 별도로 조사합니다.
- **빈 RSS 시 독립 검색:** RSS가 0건이어도 공개 웹 검색으로 정부·공식 기관 자료를 조사합니다. 출처 링크만 있는 검색 결과는 사실 근거로 취급하지 않고, 근거 문장이 인용된 경우만 자료로 채택합니다.
- **원고 후보 누락 개선:** 자동 키워드 묶음의 ID가 겹치지 않는다는 이유만으로 인용 근거가 있는 글을 탈락시키지 않습니다. 대신 두 독립 출처와 동일한 구체 시장의 관련성 및 실제 숫자 근거를 검수합니다.
- **정확한 수집 진단:** RSS가 완전히 실패한 것과 날짜·주제 필터로 걸러진 것을 구분하며, 1차/2차 검색에서 확보한 독립 URL 수와 작성된 원고 수를 기록합니다. 여전히 신규 보고서 0편은 경고로 표시됩니다.
- **호출 비용:** AI 웹 검색은 기본적으로 2회 실행됩니다. 비용·실행시간을 줄이려면 GitHub Actions의 `SEAFOOD_RESEARCH_ROUNDS: '1'`로 바꿀 수 있습니다. 자료 품질이 낮으면 3편을 억지로 만들지 않습니다.
- **범위:** 기존 UI 「주요 이슈와 시장 전망」 유지. 기존 `site/data.json` 및 금융시장 사이트는 수정하지 않습니다. 해수부/KAMIS 외부 API 인증·실데이터 실패는 별도 점검해야 합니다.

## v5.6 수집범위·공공데이터 진단 개선 (2026-11-11)

- 구글 뉴스 검색을 긴 키워드 AND 검색에서 간결한 주제별 OR 검색으로 바꾸고, 최근 **30일간의 보도**를 검색합니다. 30일 전 기사도 **원래 발표일**을 유지하며 신문 기사나 오늘의 최신 통계로 표시하지 않습니다. 보관 기사 재사용은 기존과 같이 14일 이내만 허용합니다.
- 구글 뉴스 RSS 결과가 비면 HTTP 상태, 콘텐츠 타입, XML 최상위 태그를 GitHub Actions에 기록합니다. 단순 `ValueError`만 출력하던 진단을 개선했습니다.
- KAMIS 최신 조사일 조회에 유효한 수치가 없으면 3·7·14·21·28·42일 전 조회를 시도하며, 공식 API가 제공하는 **전주·전월·전년** 비교가격을 활용합니다. 실제 관측일이 45일을 초과한 가격은 제외합니다. 같은 품목이 여러 날짜에 있으면 가장 최근의 유효한 값을 사용합니다.
- KAMIS가 XML을 반환하면 이를 파싱하며 200(매개변수 오류), 900(인증 거절)은 숨기지 않습니다. 해수부 MOF가 원자료 0건을 반환할 때 결과코드·총건수·응답 구조를 별도 로그에 남깁니다.
- `health_check.py`는 뉴스 검색이 다수 실패하거나 MOF·KAMIS 수치가 모두 없으면 경고합니다. 코드를 통과했다고 실시간 외부 API 수집까지 성공했다는 의미는 아닙니다.
- GitHub 적용 절차는 `QUICK_START_KO.md` 참조. `site/data.json` 보존, 금융 대시보드와 별개입니다.

## 기존 v4 → v5 변경 내역

- 연어 수출가격과 환율 위주였던 수치 분석에 **해양수산부 HSK 수출입 물량·금액·계산 평균단가**와 **aT KAMIS 도매·소매 조사 가격**을 새로 연결했습니다. 두 공공 API는 별도 인증키가 있어야 작동합니다. 키를 넣지 않으면 공식 숫자를 채워 넣지 않습니다.
- 노르웨이 SSB에서 주간 **가격과 물량을 동일 주차로 결합**할 수 있으면 합쳐서 비교합니다. 물량 API가 실패하면 기존 가격만 별도 표시합니다.
- 기사 선정은 뉴스 수만 보지 않고 대형마트 재편·어종 수급·수입 대체·회초밥/가공식품·식품안전·일본/미국 수출 등 **시장 변화 유형별 파급력과 근거**를 우선 고려합니다. 특정 어종을 억지로 균등 분배하지 않습니다.
- AI 심층 분석은 주요 이슈를 선정하고 웹 검색으로 공식 통계·보도/공시를 조사한 뒤 작성합니다. 작성 기준은 자료 연결과 관측에 따른 구체적인 전망입니다. 실제 실행 시마다 품질이 보장되는 것은 아닙니다.
- 02번은 01번과 같은 지표를 썼다는 이유만으로 글을 생략하지 않습니다. 실제 물량/금액/단가 등 공식 수치가 있으면 분석을 생성하고, 모델 결과가 실패한 경우에는 **AI 심층 분석이라고 주장하지 않는 계산 해설**로 표시합니다.
- 의미 없이 비어 있던 독립된 ‘더 살펴볼 쟁점’ 탭 삭제. 전망과 후속 지표는 각 분석의 본문에 포함합니다.
- 과거 샘플은 **홈플러스 유통망 / 국산·원양 오징어 / 노르웨이 연어** 3편이며 모두 과거 자료를 이용한 데모로 분명하게 구분됩니다.

## GitHub Secrets

| 이름 | 필요 여부 | 역할 |
| --- | --- | --- |
| `OPENAI_API_KEY` | AI 분석에 필수 | GPT-6.1 Sol의 심층 분석과 웹 검색 |
| `ECOS_API_KEY` | 선택 | 한국은행 환율 API |
| `MOF_API_KEY` | 수출입 통계에 필요 | 공공데이터포털에서 **해양수산부_수산물 HSK품목별 수출입 현황** 이용신청 후 발급한 서비스키 |
| `KAMIS_API_KEY` | 도소매 가격에 필요 | aT KAMIS Open API 신청 후 발급한 인증키 |
| `KAMIS_API_ID` | KAMIS 사용 시 필요 | KAMIS 인증키 신청 시 등록한 이용자 ID (`p_cert_id`) |

KAMIS와 공공데이터포털 API 키는 `ECOS_API_KEY`와 다른 키입니다. `MOF_API_KEY`로 지정된 공공데이터포털 키는 관세청 API를 별도 신청해서 이용할 경우에도 같은 포털 키를 사용할 수 있지만, 이 프로그램은 현재 **해양수산부 HSK API**만 호출합니다.

## 업데이트 일정과 데이터 보존

`.github/workflows/daily.yml`에서 한국시간 06:00(UTC 전날 21:00) 하루 1회 자동 실행합니다. 수동 실행은 언제나 가능합니다. 신규 생성에 실패하면 저장소의 `site/data.json`에 남아 있는 **마지막 유효 리포트의 원래 날짜**를 명시해서 보여줍니다. 샘플 데모는 신규 리포트로 취급하지 않습니다.

## 데이터 해석시 주의

- HSK 수출입 금액(미국 달러) / 중량(킬로그램) = **통관 평균단가**입니다. 실제 산지 매입단가, 개별 계약단가, 국내 소매가격은 아닙니다.
- HSK의 동일 코드와 동일 가공형태가 있는 경우에만 전년 동월과 합산 비교합니다. 코드 구성의 누락이 크면 비교를 제외합니다. 코드의 실제 의미와 변경 이력은 원자료에서 확인해야 합니다.
- KAMIS는 조사 품목·품종·등급·단위를 같이 보여줍니다. 산지·도매·소매를 동일 가격으로 취급하지 않습니다.
- SSB 주간 수출가격과 한국의 월간 통관가격은 집계 주기·통화·상품 규격이 다릅니다.
- KMI 광어·우럭 등의 관측 보고서는 **원문 링크와 뉴스 조사 대상**으로 포함하지만, 검증된 안정적 API가 없어 아직 매월 수치를 기계적으로 파싱해 자동 시계열로 만드는 단계는 구현하지 않았습니다.
- 이 프로젝트에는 회사 내부 가격·실적·회의 문서·거래처 계약정보를 포함하지 않았으며 외부 OpenAI 요청에도 보내지 않습니다.
