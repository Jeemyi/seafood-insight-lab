SEAFOOD INSIGHT LAB v5.1 - 적용 안내

1. 기존 seafood-insight-lab GitHub 저장소의 Code 탭을 여세요.
2. Add file -> Upload files로 업데이트 ZIP에 들어 있는 코드 파일을 모두 업로드합니다.
   핵심: build.py, seafood_ai.py, seafood_data.py, template.html.
   새 파일 이외의 기존 파일은 삭제하지 마세요.
3. Commit changes를 눌러 저장합니다.
4. Actions -> Daily SEAFOOD INSIGHT LAB -> Run workflow를 실행합니다.

한국시간 오전 6시 1회와 GPT-6.1 Sol 설정은 그대로 유지합니다.
OPENAI_API_KEY / ECOS_API_KEY는 변경할 필요 없습니다.
MOF_API_KEY, KAMIS_API_KEY, KAMIS_API_ID가 등록되지 않으면 품목별 공식 지표가 부족합니다.

중요: 이번 수정은 '환율 단독 분석'과 '단일 데이터의 긴 반복 해설'을 차단하는
게시구조 패치입니다. 외부 API와 OpenAI의 실제 생성 결과를 여기서 확인하지 못했기 때문에
매일 심층 분석이 충분히 생성된다고 보장하지 않습니다.
